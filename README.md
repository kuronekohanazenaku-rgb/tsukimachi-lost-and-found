# 忘れもの預かり所

全10話の物語と謎解きを楽しむブラウザーゲームの試作版です。

[ゲームを遊ぶ](https://kuronekohanazenaku-rgb.github.io/tsukimachi-lost-and-found/)

iPhoneのSafariやPCブラウザーから遊べます。インストール・Expoログインは不要です。

- 進行と音量設定は、遊んだブラウザーに自動保存します。ブラウザーのデータを消すと進行も失われます。
- BGMはタイトルまたは設定で再生してください。通常時は3曲を順番に再生します。
- このリポジトリは公開用HTML・JavaScript・画像・音源を管理します。開発用サーバーは不要です。
- 画像・音楽・物語・コードの再配布や再利用の許諾は、この公開によって付与するものではありません。
